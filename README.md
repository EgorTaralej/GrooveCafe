# Groove Café - Уебсайт за музикално кафене 🎵☕

Groove Café е фронтенд макет на сайт за кафене с плочи и музика на живо. Посетителите разглеждат менюто и предстоящите събития и резервират места, а администраторът управлява съдържанието от собствен панел. Проектът е само фронтенд, без бекенд, а данните се пазят в браузъра.

## ✨ Основни функционалности

- **Резервации за събития:** модален прозорец с име, телефон, дата, предпочитан час, брой гости и бележки. Формата не позволява повече гости от свободните места, а при изчерпани места бутонът „Резервирай“ се изключва.
- **Меню по категории:** цялото меню е на отделна страница, а на началната има плочки с категориите, които водят директно до съответната секция (`/menu#wine`).
- **Админ панел:** добавяне, редакция и изтриване на събития, промяна на броя резервирани места и редакция на менюто (категории, артикули, цени).
- **Предстоящи събития:** минали събития се скриват автоматично, а при тези без снимка се показва място за снимка.
- **Страници „За нас“ и „Контакти“:** работно време, адрес с карта и контактна форма с брояч на символите.
- **Бутон „Обади се“:** директно обаждане от мобилно устройство.
- **Адаптивен дизайн:** тъмна тема в кехлибарени тонове („кафене на приглушена светлина“), оптимизирана за мобилни устройства и десктоп.

## 🛠️ Технологичен стек

- **Фронтенд:** React 18, Vite, TypeScript
- **Стилове:** Tailwind CSS 3
- **Навигация:** React Router 6
- **Данни:** примерни данни в `src/data/`, а промените от админа се пазят в `localStorage`

## 🧩 Технически решения

- **Без `useEffect`:** скролът, затварянето на мобилното меню и модалните прозорци са решени чрез `useSyncExternalStore`, ref callbacks и адаптиране на state по време на render.
- **Слой за данни:** събитията и менюто минават през малък външен store (`src/store/`), който чете и пише в `localStorage`. Той може да се замени с извиквания към истински бекенд, без да се променят компонентите.
- **Типизиране:** TypeScript в строг режим, общи типове в `src/types/`.
- **Съдържанието е отделено от кода:** текстове, събития и меню са в `src/data/`, затова сайтът се пренастройва без да се пипат компонентите.

## 🚀 Инсталация и стартиране

### Системни изисквания

- Node.js (v18 или по-висока)

### Инструкции за инсталиране

Клониране на хранилището:

```bash
git clone https://github.com/ТВОЕТО-ИМЕ/groove-cafe.git
cd groove-cafe
```

Инсталиране и стартиране:

```bash
npm install
npm run dev      # локално
npm run build    # проверка на типовете + production build
```

### Админ панел

Адрес: `/admin`, демо парола: `demo1234` (променя се във `src/config/admin.ts` или чрез `VITE_ADMIN_PASSWORD` във файл `.env`).

> **Демо ограничение:** няма бекенд. Паролата е в кода, а данните са само в браузъра на този, който ги променя. За реална употреба трябват база данни и защитен вход.

## 🎨 Персонализиране

- Име, адрес, телефони, работно време: `src/data/site.ts`
- Събития: `src/data/events.ts` (датите са относителни спрямо днес, затова винаги са предстоящи)
- Меню и цени: `src/data/menu.ts`
- Лого: `src/config/brand.ts`. Докато е празно, се показва временна SVG плоча.
- Снимки: папка `public/images/` (по желание, без тях се показват места за снимки)

## 📁 Структура

```
src/
├─ config/        brand.ts (лого) · admin.ts (парола)
├─ data/          site · events · menu · about · contact
├─ store/         createStore · eventsStore · menuStore · authStore
├─ types/         CafeEvent, MenuCategory, MenuItem, SiteInfo
├─ lib/           форматиране на дати и часове
├─ components/    layout · ui · sections · events
├─ features/      reservation · contact · admin
└─ pages/         Home · Menu · Events · About · Contact · Admin · NotFound
```
